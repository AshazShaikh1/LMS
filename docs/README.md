## Agent Workflow

Before implementing a feature:
1. Read the relevant documentation.
2. Inspect the existing code.
3. Identify dependencies.
4. Implement the smallest complete solution.
5. Test the feature.
6. Update documentation if the implementation changes a decision or requirement.

Do not jump ahead through the roadmap without a working foundation.
