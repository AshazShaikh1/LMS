# LMS — Project Idea

## Overview
A web-based Learning Management System (LMS) that centralizes course materials, assignments, submissions, grading, announcements, quizzes, and academic performance.

The system has three primary roles:
- Student
- Teacher / Instructor
- Admin

## Problem
Traditional education workflows often scatter notes, assignments, submissions, announcements, and grades across physical paperwork or different digital tools. The LMS provides one centralized platform.

## Core User Flows

### Student
1. Register / login
2. View available courses
3. Enroll in a course
4. View/download course materials
5. View announcements
6. View assignments
7. Submit assignments
8. Attempt quizzes where enabled
9. View grades/results
10. Manage profile
11. Logout

### Teacher
1. Login
2. Create/manage courses
3. Upload course materials
4. Post announcements
5. Create assignments
6. Create quizzes
7. View student submissions
8. Grade submissions
9. Publish/view results
10. Track student progress

### Admin
1. Login
2. Manage users
3. Manage courses
4. Oversee the LMS
5. Perform administrative operations

## Scope

### In Scope
- Registration and login
- Role-based access
- Course management
- Course enrollment
- Course materials
- File uploads/downloads
- Announcements
- Assignment submission
- Teacher grading
- Gradebook/performance tracking
- Quiz functionality
- Student results
- Admin/user management

### Out of Scope
- Live video conferencing
- Video streaming as a core classroom feature
- AI proctoring
- Online fee payment
- Private chat/messaging
- Automatic certificate generation

## Priority

### Must Have
- Authentication
- Student/Teacher roles
- Course material upload/download
- Course enrollment
- Assignment submission
- Teacher grading
- Student results

### Should Have
- Announcements / notice board
- Basic performance tracking

### Could Have
- Discussion forum
- Additional quiz functionality

### Won't Have
- Live virtual classrooms

## Project Goal
Build a clean, functional, maintainable LMS suitable for an academic project while keeping the implementation understandable and demonstrable in a viva.
