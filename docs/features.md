# LMS — Feature Specification

## Authentication
- Student registration
- Teacher registration/admin-created teacher accounts depending on final decision
- Login
- Logout
- Session persistence
- Role-based access
- Profile

## Student
- Dashboard
- Course catalog
- Enrolled courses
- Course details
- Materials
- Announcements
- Assignments
- Submission upload
- Submission status
- Grades
- Quiz attempts
- Results

## Teacher
- Dashboard
- Course management
- Materials management
- Announcements
- Assignment management
- Submission review
- Grading
- Quiz management
- Student progress/results

## Admin
- Dashboard
- User management
- Course oversight
- Basic system management

## UX States
Every major feature should support:
- Loading
- Empty
- Success
- Error
- Unauthorized
- Not found

## MVP Boundary
Do not implement:
- Live video classes
- AI proctoring
- Payment gateway
- Private messaging
- Automatic certificates
unless explicitly requested later.
