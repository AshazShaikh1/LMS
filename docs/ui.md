# LMS — UI Direction

## General Style
- Clean academic dashboard
- Professional but not corporate-heavy
- Simple navigation
- Responsive
- Clear hierarchy
- Accessible contrast
- Consistent spacing and typography

## Role Dashboards

### Student
Show:
- Enrolled courses
- Upcoming assignments
- Recent announcements
- Recent grades
- Quiz/results summary

### Teacher
Show:
- Courses
- Pending submissions
- Upcoming deadlines
- Recent announcements
- Student performance summary

### Admin
Show:
- Users
- Courses
- Basic system statistics
- Administrative actions

## Components
Create reusable components for:
- Navbar/sidebar
- Cards
- Tables
- Forms
- Dialogs
- File upload
- Status badges
- Empty states
- Loading states
- Error states
